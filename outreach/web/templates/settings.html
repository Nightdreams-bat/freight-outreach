Sending limits
Reminder check interval - how often the automation wakes up and looks for meetings ~24h away.
Reminder window - how wide that "~24h" net is. Kept equal to the interval so two consecutive checks always overlap and nobody falls through the gap between them.
Max reminders per run - a safety brake. If one scan ever matches more than this, it sends none and warns you instead, in case of a data mistake (e.g. many rows sharing one date).
Daily send cap - total cold + reminder emails allowed per day, combined. Keeps the account well under Gmail's own daily limit so it doesn't get flagged as spam.
